# ブロック崩しゲーム

## 学習ポイント
`CompositionTarget.Rendering`によるゲームループ、当たり判定(矩形/円の衝突判定)、キー入力によるリアルタイム操作

## 概要
`CompositionTarget.Rendering`によるゲームループでボール・パドル・ブロックの当たり判定を実装するブロック崩しゲーム。

## 実装メモ
- **ゲームロジックの分離**: `GameEngine`(UI非依存の純粋ロジック)がボール・パドル・ブロックの状態を保持し、
  `Update(deltaSeconds)`で1フレーム分の状態遷移(移動・当たり判定・スコア・ライフ・クリア/ゲームオーバー判定)を
  行う。乱数を使わず初期配置は固定パターンとしたことで、`ForceBallState`(テスト専用API)と組み合わせて
  決定的にテストできる
- **当たり判定**: `CollisionDetector.TryReflect`が円の中心と矩形上の最近接点との距離で衝突を判定し、貫入の
  浅い軸(水平/垂直)の速度成分を反転させる。壁・ブロックはこの単純な軸反転で反射する
- **パドルの反射角度**: `CollisionDetector.ReflectOffPaddle`はパドル中央からの当たり位置(-1〜+1に正規化)に
  応じて反射角度(最大60度)を変える専用ロジックとし、中央に当たるほど真上寄り、端に近いほど斜め方向に
  反射するようにした
- **ゲームループ**: `MainWindow`は`CompositionTarget.Rendering`イベントでフレームごとに`Stopwatch`の経過時間を
  `GameEngine.Update()`に渡す。タブ切り替え等で極端に大きいdeltaが発生した場合に備え、1フレームの経過時間は
  0.1秒を上限にクランプしている
- **入力**: `KeyDown`/`KeyUp`(左右矢印キー)で`GameEngine.SetPaddleDirection`を呼び、押している間だけパドルが
  移動する
- **描画**: ブロックは`Rectangle`、ボールは`Ellipse`をCanvas上にあらかじめ生成しておき、毎フレーム
  `Canvas.SetLeft`/`SetTop`で位置を同期する(破壊済みブロックは`Visibility.Collapsed`にする)

## 動作確認(UI Automation)
- 右矢印キー(`keybd_event`)でパドルが右へ移動することを実機で確認
- 数秒間放置してボールが自動で動き続けた結果、スコアが0→70(ブロック7個破壊相当)まで増加し、
  ライフが3→2に減少する(ボール落下)ことを確認(スクリーンショット取得済み)
- 単体テストで壁反射・パドル反射(角度変化)・ブロック破壊とスコア加算・全ブロック破壊時のクリア判定・
  ライフ0でのゲームオーバー判定・Restartでの初期化を検証済み
