# ライフゲーム(Conway's Game of Life)

## 学習ポイント
2Dグリッド描画、Bitmap操作、タイマー駆動更新

## 概要
コンウェイのライフゲームのシミュレーション&可視化アプリ。マウスクリックでセルの初期配置を設定し、再生/一時停止/リセット/速度調整ができる。

## 実装メモ
- ルール判定は`GameOfLifeEngine`(`bool[,]`で盤面を保持する、UIフレームワーク非依存の純粋なクラス。既存アプリの`CountdownEngine`と同じ方針)に切り出し、誕生・生存・過疎・過密の各ルールとブリンカー(点滅パターン)の1世代遷移を単体テストした。盤面外は近傍としてカウントしない(端は折り返さない)
- 描画は`WriteableBitmap`ではなく`Canvas`+`Rectangle`群を採用。起動時に全セル分の`Rectangle`を1度だけ生成し、以降は`Fill`色の更新のみで再描画する。この描画処理・マウスクリックでのセル配置・`DispatcherTimer`による自動進行は全てコードビハインドに閉じ込め、ViewModelは`GameOfLifeEngine`の状態と実行状態(再生/停止・世代・速度)のみを扱う
- `MainViewModel`に`BoardChanged`イベントを用意した。`Generation`プロパティの変更通知だけに頼ると、世代0のままリセットした場合(値が変化しないため`PropertyChanged`が発火しない)に盤面の再描画が行われないバグがあったため、盤面の内容が変わるタイミング(1世代進行・リセット)で明示的に発火させるイベントとして分離した
- **UI Automationでの気づき**: `Canvas`(および`Border`等の装飾専用パネル)は既定では`AutomationPeer`を持たず、`AutomationProperties.AutomationId`を設定してもUI Automationの`FindFirst`で発見できない。本アプリの実機検証では、隣接するツールバーボタン(自動化ペアを持つ`Button`)の座標とXAML上の既知のレイアウト(余白・行間隔)から`Canvas`の位置を逆算してクリック座標を求めることで対応した
- UI Automationで実機を操作し、以下を確認済み:
  - グリッドを実際にマウスクリックしてブリンカー(横3連続セル)を配置できること
  - 「再生/一時停止」で自動進行が始まり、世代数が増加すること。ブリンカーは周期2の振動パターンのため、偶数世代(検証では6世代後)で配置直後と同じ向き(横向き)に戻ることを確認し、ルール実装の正しさを裏付けた
  - 一時停止で世代の進行が止まること
  - 「リセット」で盤面が空になり世代が0に戻ること
