# じゃんけんゲーム

## 学習ポイント
Random、簡単な状態管理

## 概要
プレイヤーがグー/チョキ/パーを選択し、CPUとランダム対戦するじゃんけんゲーム。

## 実装メモ
- 勝敗判定・CPUの手の決定・記録管理を `RockPaperScissorsEngine` クラスに分離し、xUnitでTDD(Red→Green→Refactor)により実装した
- CPUの手の決定方法はコンストラクタで `Func<Hand>` として差し替え可能にした。既定は `Random` を使うが、テストでは手を固定したデリゲートを注入することで、実際の乱数列に依存せず勝敗判定・カウント処理を決定的に検証できるようにしている
- 勝ち数/負け数/あいこ数/連勝数をエンジン内で保持し、連続プレイでは状態が継続、あいこは連勝数に影響せず、負けた時点で連勝数がリセットされる仕様にした。「リセット」ボタンで明示的に全カウントをクリアできる
- UI Automationで実機を操作し、グー/チョキ/パーそれぞれのクリックで表示が更新されること、勝敗結果がルール通りであること(グー×パー→負け、チョキ×グー→負け、パー×パー→あいこ等)、勝利時に連勝数が加算され負けでリセットされること、リセットボタンで初期状態に戻ることを確認済み
