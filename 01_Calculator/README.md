# 電卓アプリ

## 学習ポイント
ボタンイベント、四則演算、UIレイアウトの基本

## 概要
四則演算を行うシンプルな電卓アプリ。ボタンクリックによる数値入力と演算子選択、結果表示を実装する。

## 実装メモ
- 四則演算のロジック(数値・演算子の状態管理、計算実行)を `CalculatorEngine` クラスに分離し、xUnitでTDD(Red→Green→Refactor)により実装した。`MainWindow.xaml.cs` はボタンのClickイベントを`CalculatorEngine`に委譲するだけの薄いコードビハインドにしている
- ゼロ除算時は例外を投げず `Display = "Error"` を設定する方式にした。Error状態からもクリアせずに新しい数字を入力すればそのまま次の計算を開始できる(内部的には数字入力時に表示リセットフラグが立つため)
- 演算子を連続で押した場合(例: `+` の直後に `-`)は直前の演算子を上書きする。`5 + 3 + 2 =` のように演算子を連続してはさむ入力にも対応(前の計算結果を引き継いで計算)
- UI Automationでボタンをクリックし実際のアプリを操作して動作確認済み(四則演算・ゼロ除算・クリア・Error後の再入力)
