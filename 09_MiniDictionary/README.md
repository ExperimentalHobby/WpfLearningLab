# 簡易電子辞書

## 学習ポイント
Dictionary検索、TextBox+ListBoxフィルタリング

## 概要
単語を入力すると意味を検索できる簡易辞書アプリ。

## 実装メモ
- 単語検索・意味取得のロジックを `DictionaryEngine` クラスに分離し、xUnitでTDD(Red→Green→Refactor)により実装した
- `Search` は部分一致(大文字小文字を区別しない)で候補を絞り込み、辞書順にソートして返す。空クエリの場合は全単語を返す仕様にした
- 辞書データはコンストラクタで差し替え可能にし、既定ではサンプルの英単語10件を保持する。テストでは固定の小さな辞書データを注入して検証している
- コードビハインドは `TextChanged` で `Search` を呼びListBoxを更新、`SelectionChanged` で `GetMeaning` を呼び意味を表示するだけの薄い構成。該当なしの場合は「該当する単語がありません」を表示する
- UI Automationで実機を操作し、入力による絞り込み(前方一致・部分一致)、単語選択による意味表示、該当なし時のメッセージ表示、検索文字列クリアで全件表示に戻ることを確認済み
